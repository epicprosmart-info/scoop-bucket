# scoop-bucket

Scoop manifests for CoSec Shield tools. Generated by the release process of
[epicprosmart-info/cosec-cli](https://github.com/epicprosmart-info/cosec-cli) — do not edit by hand.

```powershell
scoop bucket add epicprosmart-info https://github.com/epicprosmart-info/scoop-bucket
scoop install cosec-cli                           # current: v1.0.0-rc.2
scoop update cosec-cli
```

Scoop checks the sha256 in the manifest before unpacking. Verification, license and security contact:
https://github.com/epicprosmart-info/cosec-cli
